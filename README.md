# SeedQualityAI - Система оценки качества семян с компьютерным зрением
## AgroTECH — Контроль качества семян (Трек 3)

**Коротко:** автономное прикладное решение для оценки качества семян по фотографии.  
Система сочетает компактную и робастную CNN-модель (transfer learning), предобработку и удобный кроссплатформенный интерфейс — готовое end-to-end-решение для операторов сортировочных линий и агрономов.

---

## Описание
Проект автоматически классифицирует фотографии мешков или партии семян по пяти категориям качества:  
**«отлично», «хорошо», «неплохо», «плохо», «отход».**

Сделано для реальных условий:
- работает **оффлайн**, не требует GPU;
- сохраняет результаты в базу и синхронизирует их при подключении к сети;
---

## Ключевые особенности

### 1. Модель
- **Архитектура:** transfer learning на лёгкой ResNet-подобной CNN — оптимальный баланс точности и скорости, работает на CPU.  
- **Предобработка:** resize, нормализация, аугментации (яркость, повороты, контраст, random erasing).  
- **Балансировка классов:** class weights + oversampling для компенсации дисбаланса.  
- **Инференс на CPU:** стабильная работа без GPU и интернета.
- **Степень уверенности:** модель может вывеси с какой вероятностью его результат верен.

### 2. Приложение
- **JavaScript** — интерфейс для загрузки изображений, просмотра предсказаний и истории проверок.  
- **Кроссплатформенность:** доступно с Android и iOS  
- **Оффлайн-first:** результаты сохраняются локально, при появлении сети выполняется синхронизация с облаком (или его имитацией).  
---

## Почему это решение важно
- **Готовое к внедрению:** не просто модель, а полный инструмент с интерфейсом, базой и обработкой.  
- **Робастность:** устойчива к разным условиям съёмки и освещению.  
- **Адаптивность:** автоматически улучшает точность при регулярном дообучении.

## Результаты
- **Accuracy:** ≈ 86.23% 
- **Macro F1-score:** ≈ 90.82%

## Roadmap
- **Интеграция с Telegram:** по желанию — отправка уведомлений с результатами анализа.
- **Human-in-the-loop:** оператор может подтверждать или корректировать предсказания, формируя базу для дообучения. Что необходимо первые месяцы после интеграции модели в производственную систему для улучшения точности результатов модели на реальных данных.
- **Тестовый режим:** корректировка результа через telegram-bot, который сохраняет исправленные ответы и по достижении определенного объема данные автомотическое дообучение модели.
